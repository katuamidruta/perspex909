# Perspex909 Brand Direction

## Core Idea

Perspex909 is an independent electronic music platform from Indonesia: part magazine, part label archive, part release portal, part artifact shop, part event/flyer index.

It should feel like a living archive for underground sound, visual culture, physical releases, and scene documentation. The site is not a generic music blog, not a label landing page, and not a clean agency portfolio. It is a transmission desk.

## Positioning

Perspex909 sits between:

- Mixmag-style editorial coverage
- Bandcamp release culture
- underground flyer archives
- independent label catalog
- physical artifact documentation
- Bali/SEA experimental electronic scene notes

The site can publish articles, interviews, release notes, press material, event flyers, artist pages, and shop entries, but everything should still feel like one coherent Perspex system.

## Voice

Use short, direct, atmospheric language.

Good:

- "36 tracks from the outer edge of the room."
- "A physical document of VA01."
- "Flyers, fragments, and field notes."
- "Sound, vision, and expression without boundaries."
- "Independent electronic transmissions from Indonesia."

Avoid:

- corporate startup language
- overexplaining the concept
- lifestyle-magazine fluff
- generic "discover amazing music" copy
- polished luxury-brand tone

## Visual Personality

Perspex should feel:

- raw but deliberate
- typographic
- archival
- high contrast
- industrial
- editorial
- physical, like scanned print and release objects
- tense, not decorative

It should not feel:

- beige portfolio
- glossy ecommerce
- corporate WordPress template
- EDM festival site
- cyberpunk cliche
- over-animated design demo

## Brand Objects

The site should treat these as primary brand signals:

- oversized PERSPEX909 type
- release metadata
- catalog numbers
- track counts
- dates
- flyers
- zines
- USB/product artifacts
- Bandcamp/SoundCloud/Instagram links
- black, off-white, signal red, and faint scan/noise textures

## Visual DNA From Current Assets

Perspex already has a strong graphic world. Preserve and amplify it.

Use these recurring signals:

- distressed flyers
- rough black texture
- photocopy grain
- orange/gold linework
- purple haze/noise
- metallic silver product photography
- scanned collage grids
- tracklist tables
- brutal uppercase artist lists
- alien/tribal PRSPX logo forms
- physical artifacts held in hand or placed in real environments

The best Perspex images feel documented, not staged. They should look like evidence from the scene: flyers from events, product photos from release drops, screenshots of tracklists, scans from zines, and fragments of the archive.

## Product Language

The USB release should not be described like ordinary merch. It is an artifact.

Current product from the live shop:

- title: `PRSPX VA V.1 3.0 16GB`
- format: 16GB USB 3.0
- context: Various Artists Vol. 01
- mood: post-apocalypse, emotional wreckage, survival, resilience, rebuilding from chaos
- action: purchase on Bandcamp

Preferred framing:

- "Physical document of VA01."
- "16GB embossed USB 3.0 containing the compilation archive."
- "A release object for the post-apocalyptic transmission."
- "36 tracks, printed matter, and the first Perspex compilation archive."

Avoid treating it as a normal product card with generic sales copy.

## Reference Adaptation

Reference: leonidkostetskyi.com

Take:

- monumental typography
- numbered index layout
- sparse navigation
- flat surfaces
- high-contrast theme
- minimal buttons
- strong page pacing

Change:

- make it colder, sharper, and more underground
- replace portfolio "projects" with transmissions, releases, articles, flyers, and artifacts
- use imagery as evidence: cover art, flyers, product photos, scans, video stills
- introduce metadata-heavy rows and archive tables
- allow controlled roughness through texture, scan lines, timestamps, and catalog labels

Avoid:

- personal portfolio tone
- warm designer showcase mood
- generic creative-director framing
- pure text-only pages when release/flyer/product images should carry the scene
